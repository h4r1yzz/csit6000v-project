# Brand and landing-page research

16 November 2026. Exploratory web search, not a confirmation of name, domain or trademark availability.

## Recommendation

**Repvale** is a proposed name: “rep” makes the exercise connection clear; the softer ending fits the approachable visual direction. Limited exact-name searches did not surface an obvious matching fitness app. This is a creative candidate, not a cleared name. Keep FitPilot until the user selects a name.

The previous heartbeat glyph is generic and suggests vital-sign monitoring. The new original vector mark uses an incomplete movement loop, an upward gesture and a dot suggesting a person. It works independently of the product name and has been applied to the current FitPilot wordmark. No heart-rate capability is implied.

## Names investigated

- FitPilot: direct category overlap, including [FitPilot AI Fitness](https://www.fitpilot.co.uk/) and an [App Store listing](https://apps.apple.com/es/app/fitpilot-ai/id6773685719).
- Movelo: existing [home workout app](https://play.google.com/store/apps/details?id=ar.com.movelo.twa).
- Repora: existing [gym member app](https://reporalb.com/).
- Kinora: existing [running coaching service](https://www.kinora.run/).
- MoveKind: existing [guided fitness app](https://movekind.io/en/).
- Formora: existing [movement-focused app](https://tryformora.com/).
- Repside: existing [sales software](https://repside.ai/); less suitable as a distinct software brand.

These overlaps explain why a rename should not simply use another short, familiar fitness name.

## Action hierarchy

Previously, Start a workout navigated to `#/studio`; Explore your dashboard navigated to `#/app`. They were different routes but two similar app-entry actions competed in the hero.

Now:
- Hero primary: **Open workout studio** → `#/studio`.
- Hero secondary: **See how it works** → the explanatory section on the landing page.
- Header: **Open dashboard** → `#/app`.

The camera still requires an explicit action inside the studio. Landing-page navigation does not start camera capture.

## Photo collage

Implemented a dark editorial section with six overlapping, white-bordered photographs, staggered rotations and gentle vertical motion. It follows the supplied reference's composition without using its composite image. Includes responsive rearrangement and reduced-motion support. The motion toggle was removed at the user’s request. Images are served locally. This is movement inspiration, not evidence of supported tracking: the section explicitly identifies curls, squats and arm circles as current tracking options.
